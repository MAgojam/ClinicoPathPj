Linked study inspector

Select a study button or forest point to inspect its raw counts and highlight both intervals. Hovering previews a row; leaving the point restores the selected row. Tab enters or leaves the study buttons. Up/Down arrows move between studies; Home/End reach the endpoints. Enter/Space retain their native button activation. This local view uses the precomputed Python results. Selection is transient and changes no cohort, native table, saved option or model. Native forests accompany this inspector for export.

Study inclusion preview

Check the eligible source rows to include. Hovering or inspecting a study does not change this preview. Only Apply saves inclusion and reruns native tables and forests. Count validation still covers every supplied row. Data changes require review and reapplication.
