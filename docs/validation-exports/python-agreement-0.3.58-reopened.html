Agreement: Independent Measurement Pairs (Python)

4 source row(s) excluded because one or both measurements are missing.

Partial Python port: conventional raw-scale Bland-Altman analysis of two measurements on each independent case. Normal differences, constant bias and homoscedasticity are assumed. Missing values are excluded as pairs. Rows must be independent; optional case IDs enforce known unique IDs among complete pairs. No automatic outlier deletion or clinical interchangeability verdict. ICC, CCC, categorical agreement, repeated-measurement models, ratio/log scales, regression-based limits and interactive exploration are not implemented in this core.
