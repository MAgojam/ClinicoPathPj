# Independent measurement agreement — pyagreement 0.3.58

This is the first executable core of the already registered `pyagreement` target,
under MedDecide Py → Agreement → Independent measurement pairs. It is a partial
port, not the full interrater reliability suite. The frozen meddecide 1.1.2 source
and hashes remain unchanged in the registry.

A [balanced ICC method](python-icc-integration.md) is now available in 0.3.59 under
the same analysis identifier. Bland–Altman remains the default; this page records
its original core. The ICC(2,k) interval policy remains unresolved and its native
limits are deliberately blank. See the separate ICC integration evidence.

## Core contract

Select exactly two numeric measurement columns in the same units, ordered first
minus second. One input row represents one independent case with one measurement
from each method. The optional case-ID role accepts factor or ID columns; every
complete pair must then have a known, unique ID. Missing measurement pairs are
excluded and counted as first-only missing, second-only missing or both missing.
No values are imputed, rounded, transformed or automatically treated as outliers.
At least three complete pairs and at most 5,000 supplied rows are supported.

For differences D = first − second, the outputs are:

- Bias = mean(D), with a two-sided t interval using n−1 degrees of freedom.
- Sample SD of D, using n−1 in the variance denominator.
- Lower and upper LoA = bias ± z × SD, where z is the normal quantile for the
  selected **coverage** (`baConfidenceLevel`, default .95, range .50–.99).
- Pointwise **approximate** CIs for each LoA, with half-width
  t × SD × sqrt(1/n + z²/[2(n−1)]). CI confidence is separately controlled by
  `confLevel` (default .95, range .80–.99).

This preserves the frozen baseline's difference direction, sample SD, coverage
semantics and minimum complete-pair rule. Normal differences, constant bias,
homoscedasticity and independent cases are assumptions, not established by a
successful run. These LoA CIs are approximate and pointwise, not exact tolerance
intervals or simultaneous coverage statements. Zero observed difference variance
produces collapsed intervals with an explicit warning; it does not demonstrate
population agreement. No clinical acceptability margin or interchangeability
verdict is supplied.

The [MedCalc conventional Bland–Altman manual](https://www.medcalc.org/en/manual/bland-altman-plot.php)
provides a visual/method reference and distinguishes conventional analysis from
ratio, repeated-measurement and regression-based alternatives. This implementation
is independently checked with base R rather than inferred from chart resemblance.

## Native output and interface

Data roles and uncertainty controls are expanded. Complete source pairs and the
native plot are optional. The paired audit reports all supplied rows, retained
pairs and disjoint missingness counts. The estimate table contains bias, SD and
both LoA; the pair table preserves original row IDs, optional case labels, raw
measurements, mean and difference. The static Python plot draws raw differences
against pair means and three precomputed reference lines, without jitter,
sampling or model refitting. It uses the existing native Image bridge and jamovi
palette/theme transport. No bespoke interactive view is included in this increment.

## Reproducible evidence

`tests/reference/agreement-pairs.R` creates 45 independent base-R configurations:
five data patterns × three coverage values × three CI confidence values, including
three-case, constant-difference and zero-difference fixtures. Python checks their
estimates/CIs, reversed roles, location/scale invariance, missingness, source rows,
invalid numeric storage, duplicate IDs and static plot geometry.

`data/python_agreement_examples.csv` has twelve synthetic rows: eight complete
pairs and four excluded rows. Its typed OMV is generated by
`data-raw/generate-agreement-examples.R`. No patient data are included.

Focused native tests exercise valid → incomplete/duplicate-ID/all-missing → valid
transitions, coverage/CI separation and stale plot clearing. Packaged execution,
compiler, GUI save/reopen/export and platform results must be reported separately
below; none is implied by a source unit test.
