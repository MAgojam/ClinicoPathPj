# Balanced ICC in pyagreement — 0.3.59

Use **MedDecide Py → Agreement → Continuous measurement agreement**, then
**Analysis method → Balanced intraclass correlation (ICC)**. This extends the
existing `pyagreement` identifier; there is no duplicate analysis or module.
Bland–Altman remains the default, including when opening 0.3.58 saved analyses.
Existing Bland–Altman option names, tables and plot contracts are retained.

## Data and model controls

Select 2–20 numeric rating columns, with one independent case per row. The same
set of selected raters must rate every retained case for a two-way model. For a
one-way model, columns represent balanced measurement slots. Rows missing any
selected rating are excluded together; no imputation is performed. At least two
complete cases and at most 5,000 source rows are supported. Measurements must be
scalar numeric values; dates, categorical codes and infinite values are rejected.

The optional case identifier must be known and unique among complete cases.
Repeated IDs in excluded rows do not change the retained-case design. This check
does not prove independence or identify a clinically correct rater population.
Original source-row identities and case labels are retained separately.

The expanded **Analysis and Model** panel presents the model and inferential
unit explicitly. **Uncertainty and Validation** contains the shared confidence
level (.95 by default, .80–.99). Bland–Altman coverage, pair display and plot
controls are disabled in ICC mode; they remain saved for switching back.
The retained ICC case table is optional and defaults off.

| Model | Interpretation | Confidence limits in this core |
|---|---|---|
| ICC(1,1) | One-way random, single measurement | ANOVA F |
| ICC(1,k) | One-way random, mean of k measurements | ANOVA F |
| ICC(2,1) | Two-way random, absolute agreement, single rater | Approximate F/Satterthwaite |
| ICC(2,k) | Two-way random, absolute agreement, mean of k raters | **Unavailable** |
| ICC(3,1) | Two-way mixed, consistency, single rater | ANOVA F |
| ICC(3,k) | Two-way mixed, consistency, mean of k raters | ANOVA F |

ICC(2,k) reports its estimate with blank limits and a notice explaining the
omission. The requested confidence level remains visible but does not imply
that an interval exists. Do not change the inferential unit solely to obtain an
interval. The [coverage study](python-icc-coverage-study.md) explains the unresolved
interval policy; neither candidate formula is emitted as a native result.

Normal, homoscedastic ANOVA errors and the selected random/fixed-rater design
underpin intervals. Negative unconstrained coefficients are retained. A ratio
above one from inadmissible estimated variance is withheld, while degenerate or
numerically unresolved components suppress inference. No clinical bands or
automatic interchangeability verdict are assigned. Repeated, unbalanced and
hierarchical models, bootstrap inference, CCC, categorical agreement, F tests and
sample-size calculations remain omitted. An ICC does not replace examination
of measurement differences using Bland–Altman.

## Native outputs and examples

- **ICC Complete-Case Audit:** supplied rows, complete cases, exclusions and
  number of rater columns.
- **Intraclass Correlation:** explicit model/unit, estimate, available limits
  and requested confidence.
- **ICC Rater Columns:** selected column names and positions.
- **Retained Independent ICC Cases:** optional original source IDs and case labels.

The Data Library's **Balanced ICC Examples** has eight synthetic cases and three
raters; six cases are complete. Select Rater_A/B/C and optional Case. At the
default .95 confidence, the independent references give:

| Selection | Estimate | Lower | Upper |
|---|---:|---:|---:|
| ICC(2,1) | 0.8976427 | 0.5851486 | 0.9840597 |
| ICC(2,k) | 0.9633822 | unavailable | unavailable |
| ICC(3,1) | 0.9383917 | 0.7696399 | 0.9903562 |

The example is generated by `data-raw/generate-icc-examples.R`. No patient data
are included. All user-facing calculations still run in bundled NumPy/SciPy;
irr and psych are development oracles, not runtime dependencies.
