# Python roadmap for ClinicoPathPj

Generated 2026-10-18 from a classification of all 391 ClinicoPath (umbrella) analyses by eight review
agents, plus an audit of jamovi 28.13's dynamic features.

**How far to trust it:**
- Every numpy/scipy function cited below (233 distinct names) was checked to exist in jamovi's
  bundled scipy 1.17.1 and numpy 2.1.1.
- The behaviour behind each call was **not** checked one by one. One claim turned out wrong:
  scipy's r x c `fisher_exact` is a Monte Carlo estimate, and unseeded by default (0.7717 and
  0.7687 on two runs), where R's `fisher.test` is exact (0.7662).
- Treat each row as a screen, and validate it against its oracle before porting.

## Counts

| status | direct | implementable | hard | not_suitable |

| shipped | 7 | 14 | 5 | 35 |

- **direct:** numpy/scipy provide the core computation.
- **implementable:** numpy/scipy plus moderate code of our own.
- **hard:** needs a large numerical port (Cox with ties or strata, glmnet, flexsurv, mixed models).
- **not_suitable:** plot-first, report formatting, or data wrangling.
